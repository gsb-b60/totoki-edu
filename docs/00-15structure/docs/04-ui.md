# UI Guidelines

## Visual Style
- **Theme**: Material 3 dark mode.
- **Base Background**: `AppTheme.darkBase` (`Color.fromRGBO(18, 32, 35, 1)`)
- **Card Background**: `AppTheme.darkSurface` (`Color.fromRGBO(33, 46, 54, 1)`)
- **Primary Color**: `AppTheme.primaryTeal` (`Colors.teal`)
- **Success/Correct**: `AppTheme.greenPrimary` (`Color.fromRGBO(149, 211, 50, 1)`)
- **Error/Wrong**: `AppTheme.redPrimary` (`Color.fromRGBO(199, 73, 73, 1)`)

## Formatting & Layout Rules
- **Corners**: Rounded corners of radius `16.0` on all cards and dialogs.
- **Typography**:
  - Hero headers: `fontSize: 42`, Bold.
  - Screen Titles: `fontSize: 30`, Bold.
  - Cards / Content: `fontSize: 18` or `fontSize: 15`.
- **Spacing**:
  - Horizontal & Vertical margins: `8.0` to `16.0` pixels.
- **Interactions**:
  - Use `flip_card` package for front-to-back flashcard flips.
  - Use `swipable_stack` for swipe card mechanics.
  - Integrate subtle vibrations via `Vibration` on wrong responses.
- **Layout Constraints**:
  - Prefer bottom sheets for actions.
  - Minimize the use of disruptive modal alert dialogs.
