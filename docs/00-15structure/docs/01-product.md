# Product Spec

## Vision
Totoki helps learners acquire English vocabulary through bite-sized, gamified daily review sessions powered by an intelligent Spaced Repetition System (SRS).

## Target User
- **Busy learners** who only have 5-10 minutes per day.
- **Students** preparing for language exams like IELTS, TOEFL, or TOEIC.
- **Habit builders** looking for a low-friction daily streak.

## Core Value Loop
Open app
↓
Complete daily review (5 mins)
↓
Feel immediate progression (Streaks, Badges, Stats)
↓
Build habit to return tomorrow
