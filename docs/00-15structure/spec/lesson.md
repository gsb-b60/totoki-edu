# Spec: Daily Lesson Screen

## Purpose
A guided micro-learning session that combines the learning of new vocabulary terms and active retrieval practice of due cards.

## Layout
- **Phase indicator**: Shows "New Terms Phase" vs. "Recall Practice Phase".
- **Vocabulary Card**: Word definition, pronunciation, audio, example sentence.
- **Next Step Button**: Prompts the user to continue once they are ready.

## Interactions
- **Phase 1: Acquisition**: Presents 5 new vocabulary terms with full definitions, usage examples, and audio playback.
- **Phase 2: Reinforcement**: Feeds these newly introduced words directly into review cards.
- **Completion**: Updates statistics database, marks today's lesson as completed, and triggers streak progress visual animation.
